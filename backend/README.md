# Soc Case Management Backend

### Setup
To setup the C# backend, use the commands below to install the packages of the application.
```
dotnet build
```
This also creates the `bin` and `obj` folders that are needed to run and develop the backend.

### Temporary
There's a `.gitkeep` file in the `Features` folder. This is purely to ensure the folder gets pushed to the git. When you start working on the API endpoints, you can remove the .gitkeep file.
