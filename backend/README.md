# Soc Case Management Backend

### Setup
To setup the C# backend, use the commands below to install the packages of the application.
```
dotnet build
```
This also creates the `bin` and `obj` folders that are needed to run and develop the backend.

### Temporary
There's a `.gitkeep` file in the `Features` and `Data/Configurations`folder. This is purely to ensure the folder gets pushed to the git. even though it's empty. When you start working on the API endpoints, or DB migrations and table setup, you can remove the .gitkeep files.
